Sliqtly

Sliqtly Personal · Ubuntu and Debian

Run Sliqtly locally.

The Personal package is the Sliqtly server for one computer: the MCP endpoint your agent writes presentations through, and a viewer that plays them in your browser. It runs as a system service and keeps the presentations on your own disk.

Download (.deb, amd64) ARM (arm64)

1. Install

curl -fLo /tmp/sliqtly-personal.deb https://sliqtly.com/download/sliqtly-personal_amd64.deb
sudo apt install /tmp/sliqtly-personal.deb

On an ARM computer (a Raspberry Pi with a 64-bit system, an ARM laptop) take sliqtly-personal_arm64.deb. The service starts right away and again at every boot. Open http://localhost:8080/: the page lists your presentations, and each one plays in the viewer.

2. Connect your agent

The MCP endpoint is http://localhost:8080/mcp.

Claude Code

claude mcp add --transport http sliqtly http://localhost:8080/mcp

Cursor (~/.cursor/mcp.json)

{
  "mcpServers": {
    "sliqtly": { "url": "http://localhost:8080/mcp" }
  }
}

VS Code (.vscode/mcp.json)

{
  "servers": {
    "sliqtly": { "type": "http", "url": "http://localhost:8080/mcp" }
  }
}

Claude Desktop, which starts its servers as programs (needs Node.js)

{
  "mcpServers": {
    "sliqtly": { "command": "npx", "args": ["-y", "mcp-remote", "http://localhost:8080/mcp"] }
  }
}

Agents that run in their vendor's cloud (claude.ai connectors, ChatGPT) cannot reach a server on your own computer. Use a local client, or the hosted service at https://sliqtly.com/mcp.

3. Use the service

systemctl status sliqtly          # is it running, and since when
sudo systemctl restart sliqtly    # after changing the settings
sudo systemctl stop sliqtly       # stop it for now
sudo systemctl start sliqtly
sudo systemctl disable sliqtly    # do not start it at boot
sudo systemctl enable sliqtly     # start it at boot again
journalctl -u sliqtly -f          # follow its log

4. Choose the port

The settings are in /etc/sliqtly/sliqtly.env. To use port 8090 instead of 8080:

sudo nano /etc/sliqtly/sliqtly.env      # set PORT=8090
sudo systemctl restart sliqtly

Then open http://localhost:8090/ and point your agent at http://localhost:8090/mcp. A port below 1024 needs extra rights; pick one above it.

SettingDefaultWhat it does
PORT8080The port the server listens on.
SLIQTLY_LISTENlocalWho can connect: local (this computer only), wired (also computers on a wired network) or network (every interface).
SLIQTLY_ALLOWemptyWith wired or network: only these address ranges, e.g. 192.168.1.0/24.
SLIQTLY_URLhttp://localhost:<port>The address in the links the server gives, e.g. http://my-pc:8080 when other computers use it.
SLIQTLY_TOKENemptyWhen set, /mcp needs Authorization: Bearer <token>.
SLIQTLY_DATA/var/lib/sliqtlyWhere the presentations are kept.
SLIQTLY_BACKUP/var/lib/sliqtly-backupA daily backup of the presentations; empty turns it off.

5. Other computers

By default only your own computer can connect. To let others on your network use it, set in /etc/sliqtly/sliqtly.env:

SLIQTLY_LISTEN=network
SLIQTLY_ALLOW=192.168.1.0/24
SLIQTLY_URL=http://my-pc:8080
SLIQTLY_TOKEN=a-long-random-secret

and restart the service. Agents on those computers then add the header Authorization: Bearer a-long-random-secret (Claude Code: --header "Authorization: Bearer …").

The token protects the MCP endpoint only. Anyone who can reach the server can open the presentations on it, so open it only on a network you trust.

6. Presentations and backups

Presentations live in /var/lib/sliqtly, and a backup is taken every day into /var/lib/sliqtly-backup (mount another disk there to keep it apart). To see and check the backups:

sudo sliqtly-server backup list -repo /var/lib/sliqtly-backup
sudo sliqtly-server backup verify -repo /var/lib/sliqtly-backup

7. Update or remove

To update, download the newest package and install it the same way. The service restarts by itself, and your presentations and settings stay.

sudo apt remove sliqtly-personal    # stops it; the presentations stay
sudo apt purge sliqtly-personal     # also removes /etc/sliqtly

Removing the package leaves /var/lib/sliqtly as it is, so you can keep or delete the presentations yourself.
