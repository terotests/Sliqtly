The MCP service

One endpoint: /mcp

Sliqtly is a remote MCP server (streamable HTTP) at https://sliqtly.com/mcp. The assistant calls its tools; the presentation is laid out on the server with the same model that plays it, so what the assistant checks is what you see.

Write

A presentation from Markdown, with a theme or CSS of its own, pictures, Excel, CSV or JSON data, Vega-Lite charts and Mermaid diagrams. Later changes keep the same link.

  • create_presentation
  • update_presentation
  • bind_chart_data
  • write_workbook

Check

Every change comes back with a layout report: text that runs over, overlaps, small or faint text. The assistant can look at a slide, or at all of them at once.

  • render_slide
  • render_overview
  • sliqtly_guide

Deliver

The link to play it, and files to take elsewhere: PDF, PowerPoint, Word or a web page, each behind a download link that lasts 24 hours.

  • export_presentation
  • list_presentations
  • list_comments

Sign-in

Optional, with Google.

Without sign-in

Text-only presentations that belong to no account. Anyone with the link can open them, and they are deleted 30 days after their last change. A daily limit applies per address.

Signed in

The presentations are yours: the assistant can list and change them later, and they can carry pictures and data files. The connector asks you to sign in when you add it.
