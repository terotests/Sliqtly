Sliqtly better Slides

A lot of people seem to be asking how to convert, for example, Markdown files to PDF, PowerPoint or Word. The point being... it gets pretty expensive (and potentially slow) when the document goes through the same chat many times!

And .md files don't really have formatting. And what about charts, flowcharts, theming, not to mention pagination...

A deck and four rounds of changes, timed

We gave AI agents the same model and the same job on each platform: an 11-slide management deck from a customer spreadsheet (charts, a top-10 table, a flow diagram, a timeline, a risks table, speaker notes), styled after a reference picture. Then a manager's follow-ups: one wrong number fixed everywhere it shows, slides moved, deleted and added, the look changed, a PDF. Sliqtly makes the first version and changes the look fastest, and its edits change the deck in place. PowerPoint still looks the most finished, and its data fixes are quickest because a script regenerates every number. Sliqtly is behind on style control: fonts, card shadows and how a flow diagram is laid out.

Features

What Sliqtly does today.

PowerPoint and Google Slides are a slightly unfair yardstick for a project this young: they have decades of work behind them. Here is plainly what Sliqtly reads, draws and does today.

Charts

Vega-Lite, drawn by Sliqtly's own Vega engine (46 chart types tested against Vega):

  • bar, stacked, grouped and normalized bar, histogram
  • line, multi-series line, area, streamgraph
  • scatter, bubble, heat map, tick
  • pie, donut, text labels, layered, faceted and side-by-side charts
  • time and log scales; filter, calculate, aggregate, bin, window, fold, pivot, lookup, regression, loess, density
  • looks: flat, forge, neon, glass, cartoon, romantic
  • chart text in the deck's language (lang:)

Not yet: errorbar, errorband, impute, sample.

Diagrams

  • Mermaid: flowchart, sequence, class, state, ER, mindmap, timeline, journey, gantt, gitGraph, pie, quadrant, xychart, sankey, block, architecture, kanban, requirement, C4 context, packet, radar, treemap
  • PlantUML: sequence, class, object, component, deployment, use case, activity
  • Graphviz DOT, D2
  • a guided tour, box by box

PlantUML state, timing, mind map, Gantt are not drawn.

Diagram looks

  • classic
  • sketch (hand-drawn)
  • mermaid (pastel cards)
  • jurassic (poster)
  • cartoon (speech bubbles)
  • romantic (caption boxes)

Layouts from lists

  • process (chevron steps)
  • SWOT
  • timeline
  • cards
  • stats (key figures)
  • gallery (photo albums)

Text

  • tables, with rowspan/colspan and toned cells
  • math in LaTeX, inline and display
  • code with highlighting, line numbers and stepped lines
  • diffs
  • build steps, transitions, speaker notes

Pictures and art

  • SVG
  • PNG, JPEG, GIF, WebP
  • SmartArt (partial: 20 layouts)
  • a picture as a slide background

Data

  • inline values
  • CSV and JSON files or URLs
  • Excel workbooks kept with the deck
  • Google Sheets, read live
  • your own keys in the front matter, shown in headers and footers

Output

  • the player (HTML, a link)
  • PDF, also for print with bleed and crop marks
  • PowerPoint (.pptx, editable text, formulas as equations)
  • Word (.docx)
  • a web page (.html)
  • Markdown, with or without review comments

Themes

  • aurora, nebula, carbon, ember, midnight (dark)
  • white, corporate, pearl, hive, lattice, apex, tide, mist (light)
  • forge, foundry, site (work)
  • clinic, care, vital (health)
  • editorial (A4 pages)
  • your own CSS on top

Books and albums

  • mode: book: pages in spreads, inside and outside margins
  • a realistic 3D page turn in the viewer
  • headers, footers and page numbers

AI assistants (MCP)

  • any MCP client: Claude, ChatGPT, Cursor, VS Code…
  • create, edit and export decks; read back a layout report
  • render slides to check them
  • bind charts to data, write Excel workbooks
  • list, add and resolve review comments
  • sees what you changed by hand since its last look

Editor

  • at sliqtly.com/editor after Google sign-in
  • Markdown and the slides side by side
  • diagram and table windows for editing blocks
  • version history
  • review mode: comment pins and threads on slides
  • draw on slides, record voice and pointer while presenting
  • dark and light looks

Working together

On your own Sliqtly server:

  • rooms (projects) holding decks, folders and files
  • room chat with threads, files and link previews
  • editing the same deck together, live
  • voice calls inside a room

Wanna run local?
