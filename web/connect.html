Sliqtly

MCP · Model Context Protocol

Sliqtly for AI assistants

Connect Sliqtly to your assistant and ask it for a presentation. It writes the slides in Markdown, picks a theme, adds CSS, pictures, charts and diagrams, and gives you a link that opens the finished presentation.

https://sliqtly.com/mcp

Running Sliqtly locally? The address is http://localhost:8080/mcp (another port if you chose one); see how to run it locally.

Claude claude.ai, desktop and mobile apps

Free, Pro and Max

  1. Open Customize → Connectors (in older versions Settings → Connectors).
  2. Click Add custom connector.
  3. Name: Sliqtly. URL: https://sliqtly.com/mcp.
  4. Authentication: Sign in now keeps the presentations in your own Sliqtly account (Google). No sign-in works too, for text only: the presentations then belong to no account, are open to anyone with their link, and are deleted 30 days after their last change. Pictures and data files need sign-in.
  5. Click Add, and with sign-in, Connect: a Sliqtly page asks you to continue with Google.

Team and Enterprise

An owner adds it once under Organization settings → Connectors → Add → Custom (type Web) with the same URL. Members then find it under Customize → Connectors and click Connect.

In a chat

Open the + menu → Connectors and turn Sliqtly on. The presentation appears in the conversation and its link opens it full size.

Running Sliqtly locally? claude.ai runs in the cloud and cannot reach a server on your computer; use one of the local clients below with http://localhost:8080/mcp (how to run it locally).

Claude Code

claude mcp add --transport http sliqtly https://sliqtly.com/mcp

Add --scope user to have it in every project.

Running Sliqtly locally? claude mcp add --transport http sliqtly http://localhost:8080/mcp (how to run it locally).

ChatGPT Plus, Pro, Business, Enterprise, Edu; web

  1. Open Settings → Apps & Connectors → Advanced settings and turn on Developer mode. On Business and Enterprise a workspace owner has to allow it first.
  2. Back in Apps & Connectors, click Create.
  3. Name: Sliqtly. Description: Makes slide presentations from Markdown. MCP server URL: https://sliqtly.com/mcp. Authentication: OAuth to keep the presentations in your own Sliqtly account, or No authentication.
  4. Tick that you trust the application and click Create. With OAuth, ChatGPT then opens the Sliqtly sign-in page.

In a new chat, open + → Developer mode (or More) and choose Sliqtly. ChatGPT asks before it makes a presentation; allow it.

The menu names move between ChatGPT versions. If you do not find Developer mode under Apps & Connectors, look under Settings → Connectors → Advanced.

Running Sliqtly locally? ChatGPT runs in the cloud and cannot reach a server on your computer; use one of the local clients below with http://localhost:8080/mcp (how to run it locally).

OpenAI API Responses API, Agents SDK

{
  "type": "mcp",
  "server_label": "sliqtly",
  "server_url": "https://sliqtly.com/mcp",
  "require_approval": "never"
}

Put it in the request's tools list. In the Agents SDK use HostedMCPTool with the same tool_config.

Running Sliqtly locally? OpenAI calls the server from its own cloud, so it needs an address reachable from the internet (behind a proxy with HTTPS and SLIQTLY_TOKEN), not localhost (how to run it locally).

Cursor

Settings → Tools & MCP → New MCP server, or add this to ~/.cursor/mcp.json (every project) or .cursor/mcp.json (one project):

{
  "mcpServers": {
    "sliqtly": {
      "url": "https://sliqtly.com/mcp"
    }
  }
}

In Agent mode, ask for a presentation; Cursor asks before calling the tool.

Running Sliqtly locally? Use "url": "http://localhost:8080/mcp" (how to run it locally).

Other MCP clients

Any client that speaks MCP over Streamable HTTP works with the URL above. They connect without sign-in; clients that support MCP's OAuth sign-in can also sign in.

VS Code (GitHub Copilot)

// .vscode/mcp.json
{
  "servers": {
    "sliqtly": { "type": "http", "url": "https://sliqtly.com/mcp" }
  }
}

Windsurf

// ~/.codeium/windsurf/mcp_config.json
{
  "mcpServers": {
    "sliqtly": { "serverUrl": "https://sliqtly.com/mcp" }
  }
}

Gemini CLI

// ~/.gemini/settings.json
{
  "mcpServers": {
    "sliqtly": { "httpUrl": "https://sliqtly.com/mcp" }
  }
}

Running Sliqtly locally? Replace https://sliqtly.com/mcp with http://localhost:8080/mcp in each of these (how to run it locally).

A client that only runs local servers

npx -y mcp-remote https://sliqtly.com/mcp

Running Sliqtly locally? npx -y mcp-remote http://localhost:8080/mcp (how to run it locally).

Using it

Ask in your own words, for example:

Make a 6-slide presentation of our Q3 results with the ember theme: a bar chart of revenue by month, a diagram of the sales process, and this photo on the title slide: https://…/team.jpg
Change slide 3 to a two-column comparison and make the headings orange.

Sliqtly is provided as is, and you store data in it at your own risk: read the terms.
