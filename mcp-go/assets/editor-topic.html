Branches

A branch starts from main. Open a presentation in the branch to work on a copy of it; main stays as it is. A presentation put in the branch's folder is new in the branch. When the work is ready, merge the branch: Sliqtly opens a pull request on GitHub and merges it.

Merged and dropped branches

    Main and the branch changed the same lines. For each place, choose what stays; then check the result and save it.
